# カジュアルモード

**作るより手続きの方が長い、を避けるためのモードです。** ゴールを切って、Red を確認して、
許可ファイルを書いて、3 ブロックで締めて… は**続けるため**の仕掛けで、**試すため**の仕掛けではありません。

```bash
python3 scripts/casual.py on             # 8 時間。デプロイは許可しない
python3 scripts/casual.py on --deploy    # Sandbox へのデプロイも通す
python3 scripts/casual.py status
python3 scripts/casual.py off            # 通常モードに戻す
```

**期限つきです (既定 8 時間)。** 切り忘れた緩みは誰にも見えないので、放っておけば自動で戻ります。
印は `context/casual.yaml` で、**git には入りません** (`casual.py on` が `.gitignore` に足します)。

---

## 何が緩むか

| 緩むもの | 通常モードでは |
|---|---|
| 台帳 (`tasks/T-*.md`) と `done_when` | 「台帳の外で作業しない」。ゴールを切らないと始められない |
| TDD (Red → Green) の順 | 先にテストを書いて落ちることを確かめる |
| 「現在地 / 次にすること / そのあと」の 3 ブロックと、止まろうとしたときの差し戻し | hook が 1 回差し戻す |
| 層の越境の検査 (process 層から `db:` を直接使う等) | その場で差し戻す |
| **秘密の値をファイルに書くこと** — **git が無視する場所にだけ** | どこであれ弾く |
| `--deploy` を付けたときだけ: Sandbox へのデプロイに `authorizations.yaml` を要求しない | 人が書いた許可ファイルが要る |

## 何が緩まないか (ここが緩むと取り返しがつかない)

| 緩まないもの | 理由 |
|---|---|
| **本番系の環境名へのデプロイ** | 常に deny。本番は人が Runtime Manager から手で行う |
| **publish 前の jar の混入検査** | Exchange に上げたら組織の全員から見える。取り消せない |
| **git が追跡するファイルへの秘密の書き込み** | git に入った秘密は履歴から消せない |
| 秘密の**値そのもの**を hook の出力に書かないこと | hook の出力は会話に残る |
| 構文の検査 (壊れた XML、dwl、XSD で落ちる形) | 壊れたまま進むと、原因を探す時間の方が長くなる |

## パスワードを渡したいとき

1. **置き場所を先に作る。** git が無視する場所であることが条件です:
   ```bash
   printf 'context/environment/local.yaml\n' >> .gitignore
   ```
2. 値を渡す (会話に貼ってよい。ただし**会話の記録には残ります**。Sandbox の資格情報だけにし、
   終わったら回す (rotate) のが安全です)。
3. エージェントがその場所に書きます。`src/main/resources/config/*.yaml` のような**追跡ファイルには
   書けません** — そこには参照 (`${db.password}` など) を書き、実値は上の場所に置きます。
4. 使うときは環境変数か Mule のプロパティで渡します。

**`git status` に出る場所に書こうとしたら hook が止めます。** 止まったら置き場所を変えてください
(それは事故の 1 歩手前です。`.gitignore` に足してから書く)。

## カジュアルで進めるときの流れ

台帳も TDD も無いので、**そのまま書いて、動かして、直す**でかまいません。ただし 2 つだけ:

1. **動いたことは自分で確かめる。** `mvn -q clean test` か、実際に叩く。
   カジュアルは「確かめない」ではなく「確かめ方を強制しない」です。
2. **残す価値が出たら通常モードに戻す。** `off` にしてから、`/mule-start` で受け入れ条件を作り、
   台帳に載せ直します。**試作をそのまま本番の入口にしない。**

## 通常モードに戻すとき

```bash
python3 scripts/casual.py off
git status                      # カジュアル中に書いたものを確かめる
grep -rn "SET_\|password\|secret" src/main/resources/config/ | head   # 実値が紛れていないか
```

戻したら、hook はすべて元の強さに戻ります (台帳、TDD、締め方、層、秘密、許可ファイル)。
